                            Fusion Models
                            Each Fusion model runs a panel of models in parallel, a judge produces a structured analysis, and a main model writes the final answer.
                            Pick a provider and model for each role. Register the gateway itself as a provider to reuse gateway models. Panel size: 1–8.

                            Router Models
                            Each Router model calls a selector gateway model, then routes the original request to one explicit target.
                            Selector and targets come from chat models configured in Fallback Rules. A target can use the full fallback chain or start at a specific entry.

                            Web Search Services
                            Configure gateway services for /v1/web/search. Each service defines a gateway-visible name and an optional query-expansion model.
                            Built-in adapters run in this fixed order: Proxy → Tavily → Jina → Z.AI. Configure them in .env: PROXY_URL / TAVILY_API_KEY / JINA_API_KEY / ZAI_API_KEY. The first non-empty result wins.
                            The optional Query Model is a gateway chat LLM that expands the user query into multiple search queries.
                        

                        
                    

                    

                    

                        No web search services yet. Add the first search service to begin.
                    

                

                

                    

                        

                            Web Read Services
                            Configure gateway services for /v1/web/read. Each service defines only its gateway-visible name.
                            The gateway first tries direct HTTP fetch. If it is empty, built-in adapters run in order: Proxy → Tavily → Jina → Z.AI. Configure PROXY_URL / TAVILY_API_KEY / JINA_API_KEY / ZAI_API_KEY in .env.
                        

                        
                    

                    

                    

                        No web read services yet. Add the first read service to begin.

                            OpenRouter Free Model Ranking
                            Read-only ranking of free text OpenRouter models scored by metadata, health, latency, and lite eval checks.
                            This tab is shown only when the official OpenRouter provider and API key are configured.
                        

                        
                    

                    

                        

                            
metadata

                            
Catalog score based on pricing, context size, recency, and supported features.

                        

                        

                            
health

                            
Probe score from a small reply request.

                        

                        

                            
latency

                            
Speed bonus based on health probe latency.

                        

                        

                            
eval

                            
Lite eval score for instruction following, tools, code, arithmetic, and factual QA.

                        

                        

                            
penalty

                            
Instability points subtracted from the final score.

                        

                        

                            
latency ms

                            
Measured health probe response time in milliseconds.

                        

                        

                            
context

                            
Model context window size in tokens.

                        

                        

                            
health status

                            
Raw health probe result.

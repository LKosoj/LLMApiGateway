Web Search Services Configure gateway services for /v1/web/search. Each service only defines the gateway-visible name and (optionally) a query-expansion model. Upstream adapters are built in and fixed: Proxy → Tavily → Jina → Z.AI. Enable each by setting the corresponding env var in .env: PROXY_URL / TAVILY_API_KEY / JINA_API_KEY / ZAI_API_KEY. Adapters are tried in that order and the first non-empty result wins. The optional Query Model below each service is a gateway chat LLM used to expand the user query into multiple search queries.

Web Read Services Configure gateway services for /v1/web/read. Each service only defines the gateway-visible name. The gateway first tries a direct HTTP fetch (no API key required, with trafilatura / HTML parser / PDF / YouTube subtitles). Only if that returns empty are built-in adapters tried in fixed order: Proxy → Tavily → Jina → Z.AI. Enable each by setting PROXY_URL / TAVILY_API_KEY / JINA_API_KEY / ZAI_API_KEY in .env.

OpenRouter Free Model Ranking Read-only ranking of free text OpenRouter models scored by metadata, health, latency, and lite eval checks. The tab is shown only when the official OpenRouter provider and API key are configured. All eligible reachable models are evaluated.
metadata
Catalog score for free pricing, context size, max output, recency, and supported features such as tools, structured outputs, response format, reasoning, seed, and stop.
health
Probe score from a small “reply OK” request. Passed models get the full health bonus; imperfect or failed probes get less.
latency
Speed bonus calculated from the health probe latency. Lower latency gives more points.
eval
Lite eval score for instruction following, tool-call JSON, Python code unit tests, parameterized arithmetic, and factual QA.
penalty
Instability points subtracted from the final score, mainly for rate limits or probe errors.
latency ms
Measured response time of the health probe in milliseconds.
context
Model context window size in tokens from the OpenRouter catalog.
health status
Raw health probe result, for example passed, imperfect, http_429, timeout, or another error class.

Fallback Model Eval Manual lite eval for unique provider/model targets from configured fallback rules. The eval runs only when you press the button; it evaluates OpenAI-compatible and Anthropic targets directly and does not change routing rules.
unique target
A configured fallback route grouped by provider and model. Repeated routes are evaluated once and list all gateway models that reference them.
health
Probe score from a small “reply OK” request sent directly to the configured provider/model route.
latency
Speed bonus calculated from the health probe latency. Lower latency gives more points.
eval
Lite eval score for instruction following, tool-call JSON, Python code unit tests, arithmetic, and factual QA.
metadata
OpenRouter catalog score matched by model basename when the official openrouter provider and API key are configured. If a target has no match but other targets do, this is the median known metadata score.
penalty
Instability points subtracted from the final score, mainly for rate limits or probe errors.
latency ms
Measured response time of the health probe in milliseconds.
context
OpenRouter context length when a catalog card was matched; otherwise 0.
health status
Raw health probe result, for example passed, imperfect, http_429, missing_provider, timeout, or another error class.
